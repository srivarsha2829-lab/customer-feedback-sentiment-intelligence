# Negative-review theme guide

The NMF model is fit only on 1-2-star reviews. Human-readable names below are descriptive labels based on the model's top terms; they are not ground-truth categories.

| Theme | Working label | Top terms |
| --- | --- | --- |
| 1 | General battery performance / usage | batteries, used, brand, remote, amazon, lasted, battery, use |
| 2 | Batteries not lasting long | long, don't long, batteries long, long lasting |
| 3 | Batteries not working / purchase frustration | don't, batteries don't, don't work, work, buy, money |
| 4 | Short battery life | life, short, short life, battery, battery life, terrible |
| 5 | Tablet / charging / app feedback | good, tablet, amazon, charge, apps, product, use, like |
| 6 | Dead or partially dead batteries | dead, work, half, batteries dead, half batteries |

These labels should be used as navigation aids in the dashboard. Representative reviews should still be inspected before making a product decision.
