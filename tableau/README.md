# Tableau dashboard

The final dashboard is published on Tableau Public:

https://public.tableau.com/app/profile/sri.popuri/viz/CustomerFeedbackSentimentIntelligence/Dashboard1

## Dashboard views

- **Product Negative Feedback** — top 10 products by negative-review share after applying a minimum review-volume filter.
- **Rating Distribution** — review counts for ratings 1 through 5.
- **Monthly Negative Feedback Trend** — monthly negative-review share with low-volume months filtered out.
- **Negative Review Themes** — six exploratory themes derived from 1–2-star reviews.
- **Rating vs Text Sentiment** — heatmap comparing star ratings with model-predicted positive/negative text sentiment.

The dashboard uses processed analysis outputs rather than the raw review file. It is intentionally descriptive and interpretable and does not use an opaque composite score.
